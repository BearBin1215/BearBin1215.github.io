## 文本格式

段落中可以使用 **加粗**、*斜体*、~~删除线~~、`行内代码` 等行内样式。

链接会自动在新窗口打开：[示例链接](https://example.com)。

## 代码块

支持语法高亮：

```ts
interface Example {
  /** 名称 */
  name: string;
  /** 日期 */
  date: string;
}

function format(item: Example): string {
  return `${item.name} - ${item.date}`;
}
```

### 行内代码样式

`行内代码` 会带有边框与浅底色，与正文明显区分。
